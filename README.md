# Laser Dose Calculator

A Python script for estimating the ambient dose equivalent H*(10) from bremsstrahlung generated by an intense laser pulse interacting with a solid target.

The model supports aluminum, stainless steel, and Teflon targets, with photon attenuation through vacuum, air, and selected shielding materials. Results are reported in **mrem per laser pulse**.

## Usage

Configure the laser, target, observation angle, and material layers by editing `CONFIG` in the script or supplying a complete JSON configuration using `--config FILE.json`.

## Documentation

See [laser_dose_calculator.pdf](doc/laser_dose_calculator.pdf) for the physical model, equations, numerical methods, assumptions, and references.

## Limitations

This is an approximate radiation-dose screening tool, not a substitute for detailed radiation transport simulations or a validated shielding assessment.
